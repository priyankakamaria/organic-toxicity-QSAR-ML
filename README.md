# Explainable Machine Learning-Based QSAR Framework for Predicting Aquatic Toxicity of Organic Compounds

This repository contains the complete workflow for developing explainable machine learning-based QSAR models for predicting aquatic toxicity of organic compounds using molecular descriptors and molecular fingerprints.

## Repository Structure

- data/ : Dataset
- scripts/ : Python scripts
- output/ : Model results, figures and tables

## Machine Learning Models

- Random Forest
- Gradient Boosting
- XGBoost
- CatBoost
- Support Vector Regression

## Validation

- Train/Test Split
- 5-Fold Cross Validation
- Hyperparameter Optimization
- Y-Randomization
- Applicability Domain
- SHAP Analysis
